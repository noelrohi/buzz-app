# HTML Pages

Lets agents show a finished HTML page, such as a chart, diagram or mockup, right in the conversation.

## Getting started

1. Ask an agent to show you something as a page. It calls `html_render`, and the page appears in its message.
2. Pages run sandboxed: they can't read Buzz or your account. A link a page opens asks you first, then opens in your browser.
3. An HTML file a person posts stays a file card. Choose **Show page** to run it.
4. Other apps show the page as an `.html` file you can download.
